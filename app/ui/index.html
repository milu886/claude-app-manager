关于

Claude APP Manager

Claude 的安装与更新助手。

参考 Codex App Manager 的管理流程，接入 Claude App Mirror 的动态清单和离线安装包。

工作方式

启动时读取最新清单，按系统架构选择安装包；下载后校验 SHA-256，Windows 安装前还会验证 Authenticode 发布者。每次安装前重新检查版本，防止误降级。

Windows 支持 MSIX 安装、启动和保留个人数据的卸载；macOS 与 Linux 会打开系统安装程序，由你完成安装。此镜像没有 Claude 增量包，更新使用完整安装包。

自动检查需要 Manager 保持运行。上游镜像约每 15 分钟同步一次，检查频率无法缩短上游同步延迟。Manager 自身的在线更新尚未配置发布仓库。

这是独立的第三方管理工具，与 Anthropic 没有隶属关系。Claude 的账户、服务与授权遵循其官方规则。
