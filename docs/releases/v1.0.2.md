# 1.0.2 · Claude 后台服务与更新注册修复

- 区分 Claude 桌面进程和 Claude 自带的 `CoworkVMService` 服务。该服务以 LocalSystem 运行，进程名为 `cowork-svc.exe`；普通进程路径查询可能返回空值，不能据此认定整个包已空闲。
- 通过 SCM 读取服务信息，并核对可执行文件必须为当前已安装 Claude 包中的 `app\resources\cowork-svc.exe`，再允许管理器控制它。同名但路径不匹配的服务不会被停止。
- 桌面端未运行时，更新流程正常停止该服务、等待停止、安装并在 finally 中恢复原先运行的服务。安装失败也会尝试恢复；服务恢复失败会明确报告。
- 桌面端仍在运行时继续采用 Windows 延后注册，保留现有会话，不强制结束进程。
- 等待状态改为“等待完成注册”，不再一律声称“Claude 正在运行”。界面显示实际进程或后台服务，并提供可用的“完成更新”按钮；重启后仍可复用已校验缓存继续安装。
- 实际验证：Claude 从 `3.1623.0.0` 升级至 `3.1623.1.0`，等待记录已清除，CoworkVMService 恢复运行。
- 35 项测试，包括 PowerShell 服务停止/恢复顺序、失败恢复、不干扰活跃桌面会话、服务路径归属核验、等待状态恢复后的缓存重试，以及原有下载和错误处理回归。
