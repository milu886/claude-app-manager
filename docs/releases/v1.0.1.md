# 1.0.1 · Windows 安装修复

- 修复 Windows PowerShell 继承 PowerShell 7 模块路径时，`Get-AuthenticodeSignature` 自动加载到不兼容模块而无法完成安装的问题。明确使用系统 Windows PowerShell 可执行文件和系统安全模块。
- PowerShell 以结构化 JSON 返回成功结果或完整错误；不再把 CLIXML 中的错误整体丢弃，保留部署错误码和中文说明。
- 对 MSIX 使用 `DeferRegistrationWhenPackagesAreInUse`。Windows 判定包被占用时，更新会准备就绪，完全退出 Claude 后在下次启动时完成，不强制结束应用。
- 将“等待更新生效”与“已安装”分开显示，等待状态持久化，防止重启管理器后重复提交安装。后续检测到目标版本后才报告更新完成。
- 安装检测包含 Claude 包目录内的后台组件；保留签名校验、SHA-256 校验和降级保护。
- 28 项测试覆盖原有更新链路以及中文错误、CLIXML、原生系统模块、延后更新持久化和版本复核。

Windows 的延后注册行为：[Add-AppxPackage 文档](https://learn.microsoft.com/en-us/powershell/module/appx/add-appxpackage?view=windowsserver2025-ps#example-2-update-an-app-but-defer-registration-until-the-app-has-closed)。
