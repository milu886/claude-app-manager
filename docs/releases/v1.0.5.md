# 1.0.5 · GitHub 请求限制修复

- 修复“仅 GitHub”模式反复出现“GitHub：更新源 HTTP 403，请稍后重试（可能达到请求限制）”。原因：未登录的 GitHub API 每个 IP 每小时只有 60 次配额，每分钟检查一次正好用满；1.0.3 起请求经系统代理发出，代理出口 IP 可能与他人共用，配额更早耗尽（实测经代理 0/60，直连 60/60）。GitHub 对返回 304 的条件请求同样计数，ETag 缓存不能节省配额。
- GitHub 版本信息改为下载发布附带的 `release-manifest.json`（通过 `releases/latest/download/` 固定地址，属于普通文件下载，不计入 API 配额）。该文件与镜像清单格式相同，包含版本、SHA-256、大小、文件名和 Anthropic 官方 CDN 固定版本地址；“国内镜像优先”模式因此无需额外请求即可同时使用官方 CDN 下载。仅在该文件不可用时回退到 API。
- 实测：经代理连续三次检查（两次“仅 GitHub”、一次“国内镜像优先”），API 配额保持 60/60，每次检查 0.4–1.5 秒。
- 62 项测试，新增“清单可用时不调用 REST API”。
